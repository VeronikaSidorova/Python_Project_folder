# Проект FOLDER

## Описание

Проект позволяет получать информацию о вакансиях с платформы hh.ru в России, сохранять ее в файл и работать с ней: добавлять, фильтровать, удалять.

## Установка

Клонируйте репозиторий
```
https://github.com/VeronikaSidorova/Python_Project_folder
```

## Тестирование
Наш проект покрыт тестами. Для их запуска выполните команду:
```
pytest
```
